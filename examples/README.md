Keep this folder small and deliberate: 8 to 15 pieces, each earning its place. Every entry gets a row below with the channel, why it is on-brand and what to copy from it. Images stay under 300 KB. Emails are stored as rendered HTML where possible (better for Claude Design than a screenshot).

## Adding one

1. Pick the piece. Ask: would I be happy if every future design looked like this?
2. Export. Klaviyo: render the template to HTML. Meta/Google ad: PNG or JPG, downsized to 1200px on the long side.
3. Name it `channel-yyyy-mm-short-slug.ext`, e.g. `edm-2026-03-cooling-launch.html`.
4. Add a row above. Two sentences maximum per cell.
