## Glossary

| Field | Value | Meaning |
| :-: | :-: | :-: |
| Concept | Untested | New concept being tested for the first time |
| Concept | Iteration | Building on something that's previously worked |
| Concept | WinnerClone | Near-direct rebuild of a current winner (different creator, same hook) |
| Concept | TopOfFunnelTest | Broad/awareness-stage test, usually unaware audience |
| Concept | Refresh | Existing winner refreshed for fatigue (creative edited, hook preserved) |
| AwarenessStage | Unaware | Doesn't know they have a problem |
| AwarenessStage | Problemaware | Knows the problem; doesn't know solutions exist |
| AwarenessStage | Solutionaware | Knows solutions exist; doesn't know us |
| AwarenessStage | Productaware | Knows us; hasn't committed |
| AwarenessStage | Mostaware | Knows us; just needs the nudge |
| AwarenessStage | Brandaware | Already a customer or brand-familiar (legacy term — equivalent to Productaware) |
| Persona | HomeInterior | Aesthetics-first buyer — cares how it looks in the room |
| Persona | FitnessRecovery | Buyer who frames sleep as recovery / performance |
| Persona | HotSleeper | Runs hot at night, primary problem is temperature |
| Persona | SleepGeneral | Generic sleep-quality buyer, no specific sub-need |
| Persona | PetHair | Dealing with pet hair / pet-on-bed concerns |
| Persona | CoupleSleeper | Couples / sleep-disturbed-by-partner messaging |
| Persona | Eco | Eco-conscious / sustainability-led buyer |
| Persona | Allergies | Allergy / sensitive-skin angle |
| Angle | USP | Unique selling proposition — product feature claim |
| Angle | ProblemHighlight | Lead with the problem the product solves |
| Angle | SocialProof | Reviews, ratings, customer counts, press mentions |
| Angle | Origin | Founder story, why we built this |
| Angle | ComparisonClaim | vs cotton / vs competitor / vs old sheets |
| Angle | ValueStack | What you get for the price |
| Angle | Education | Teaching about the category (e.g. how bamboo works) |
| Angle | Aspiration | Lifestyle dream-state, no explicit claim |
| Angle | Urgency | Scarcity / time-limited / FOMO |
| Angle | Trust | Warranties, returns, expert endorsement |
| Angle | PriceLed | Price / discount is the headline |
| Angle | BundleLed | Bundle savings / value-stacking |
| Vehicle | UGC | User-generated content style, casual smartphone-ish |
| Vehicle | FounderPOV | Founder talking to camera |
| Vehicle | Lifestyle | Aspirational, polished lifestyle imagery |
| Vehicle | Demo | Product in action — fold test, drape, feel, performance |
| Vehicle | Comparison | Visual side-by-side, before/after, vs other product |
| Vehicle | Static | Single image with copy / text overlay |
| Vehicle | Podcast | Sit-down interview / podcast-style clip |
| Vehicle | BroadStory | Narrative / cinematic story, longer form |
| Vehicle | Meme | Humour, cultural-reference, low-fi |
| Vehicle | Testimonial | Talking-head customer review |
| Vehicle | ReviewScroll | Screen-recording of real reviews |
| Vehicle | AIGenerated | Predominantly AI-generated imagery / video |
| Vehicle | Collab | Co-created with a creator partner (named in Source) |
| Vehicle | Stopmotion | Stop-motion / claymation / hand-animated |
| Vehicle | Recut | Recut of existing footage (low-cost variant) |
| CampaignMoment | Evergreen | Always-on, not tied to a specific moment |
| CampaignMoment | NewRelease | Tied to a new product launch |
| CampaignMoment | Restock | Product back in stock |
| CampaignMoment | EOFY | End of financial year sale (June) |
| CampaignMoment | BFCM / BlackFriday / CyberMonday | Black Friday / Cyber Monday (November) |
| CampaignMoment | BoxingDay | Boxing Day sale (December) |
| CampaignMoment | MothersDay / FathersDay / Christmas / Valentines / Easter | Holiday calendar moments |
| CampaignMoment | ANZACDay / AustraliaDay | AU national days |
| CampaignMoment | WinterSale / SummerSale / MidyearSale / NewYear | Seasonal pushes |
| CampaignMoment | Bundles | Bundle-focused promotion |
| CampaignMoment | BirthdaySale | Ecoy birthday sale (e.g. previously called BDAY26) |
| CampaignMoment | AmbiLaunch / CordLaunch | Specific collection launches |
| CampaignMoment | CollabPost / PartneredAd | Creator-collaboration content |
| CampaignMoment | Seeding | Product seeded to creators, no formal partnership |
